# Air Quality Alert System (AirAware)
Python Programming Mini Project, Sem 3

## Problem
People do not know when the air around them is unsafe or what to do about it.
AirAware shows live air quality for a city and gives health advice based on
who the user is (child, asthma patient, elderly, healthy adult).

## Features (planned)
- Live AQI for any city
- Health advice by user profile
- Email alerts when air becomes unsafe
- Charts and trends
